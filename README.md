# KotaKayu-Seasons
My custom pack to the KotaKayu server (known as Oakwood City).


##A little story
KotaKayu, which is "City of Woods" in English, is a city that me and my friends have been building since 2020.
There are so many memories that I wish I could go back in time to build this city with them.

However, for years, I feel like playing Minecraft as vanilla is a bit boring, so I want to create this season resource pack by myself, so I can see the world changes as the year progresses.
