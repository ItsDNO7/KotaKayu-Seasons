# KotaKayu-Seasons
My custom pack to the KotaKayu server (known as Oakwood City).


## A little story
KotaKayu, which is "City of Woods" in English, is a city that me and my friends have been building since 2020.
There are so many memories that I wish I could go back in time to build this city with them.

However, for years, I feel like playing Minecraft as vanilla is a bit boring, so I want to create this season resource pack by myself, so I can see the world changes as the year progresses. Instead of using existing packs from the Minecraft community, I create this to give special colours for my special world.

Besides, I like customising my world as I feel them as a hobby.

## Hi there!
Thank you for reading. I know this is like writing essays but I just want to express the reason why I created this.

# Vegetations
Deciduous plants:
- Default (Oak, Dark Oak, Jungle, Acacia): Complete four seasons
- Pale Oak: white-ish in winter, green-ish in summer
- Birch: Four seasons with yellow-reddish colour in autumn
- Cherry: Four seasons with dark-red colour in autumn
- Spruce: Four seasons with bright-yellow in autumn (now becomes Larch)
- Azalea: The only evergreen
